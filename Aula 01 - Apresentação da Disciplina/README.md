# Aula 01 — Apresentação e Contextualização

##  Resumo da Aula

Nesta aula foi apresentada a ementa da disciplina de **Frameworks Front-end** e o contexto histórico da evolução do desenvolvimento web:

* **Web Estática vs. Web Dinâmica:** transição de páginas puramente HTML/CSS para aplicações interativas com JavaScript no navegador.
* **Vanilla JS:** uso de JavaScript puro (manipulação direta do DOM, eventos e `localStorage`) antes da adoção de abstrações modernas.
* **Por que surgiram os Frameworks Front-end:** necessidade de componentização, reatividade de estado, escalabilidade, padronização em equipe e melhor desempenho na atualização da interface.
* **Fluxo de Entrega Moderno:** versionamento de código com Git/GitHub integrado a plataformas de deploy contínuo como a Vercel.
