#  Frameworks Front-end

> Repositório dedicado aos meus estudos de Front-end, reunindo resumos das aulas, anotações e links dos projetos desenvolvidos na disciplina de Frameworks Front-end.

##  Objetivo

Organizar o conteúdo estudado, facilitar revisões e documentar minha evolução no desenvolvimento front-end ao longo da disciplina.

##  Estrutura

```text
frameworks-frontend/
├── Aula 01 - Apresentação da Disciplina/
├── Aula 02 - Configuração do Ambiente de Desenvolvimento/
├── Aula 03 - Projetos/
├── Aula 04 - Consumindo APIs no Front-end/
├── Aula 05 - Criando APIs para o Front-end/
├── Aula 06 - Projetos Front-End/
├── Aula 07 - Frameworks CSS/
├── Aula 08 - Projeto React/
├── Aula 09 - Projeto React/
└── README.md
```

Cada pasta representa uma aula e contém um resumo em Markdown (`.md`) com os principais conceitos abordados, além das documentações e entregas solicitadas.

##  Conteúdo

*  Resumos das aulas
*  Conceitos e definições importantes
*  Exemplos de código
*  Boas práticas de desenvolvimento
*  Materiais e referências complementares
