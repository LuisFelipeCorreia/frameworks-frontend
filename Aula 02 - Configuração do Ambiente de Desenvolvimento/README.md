# Aula 02 — Configuração do Ambiente de Desenvolvimento

##  Resumo da Aula

Nesta aula foram abordados os fundamentos de configuração profissional de ambiente e fluxo de entrega contínua para projetos Front-end:

* **Versionamento e SemVer:** diferença entre backup e controle de versão distribuído, uso de branches, tags e Versionamento Semântico (`MAJOR.MINOR.PATCH`).
* **Git & GitHub:** configuração local (`git config`), commits semânticos e sincronização com repositórios remotos.
* **Ambiente Node.js, npm e Vite:** estrutura inicial de uma aplicação React moderna (`node_modules`, `public`, `src`, `package.json`).
* **Deploy Contínuo na Vercel:** integração direta com o GitHub para geração automática de builds e publicação em URL pública.
